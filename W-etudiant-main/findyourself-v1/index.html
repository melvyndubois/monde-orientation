📤 Comment exporter tes données
TikTok
  1. Ouvre TikTok → Profil → icône ⋮ en haut à droite
  2. Paramètres → Confidentialité → Télécharger tes données
  3. Sélectionne "Toutes les données" et le format JSON (pas TXT)
  4. Clique sur "Demander des données" — délai : 3 à 7 jours
  5. Tu reçois un e-mail avec un lien de téléchargement → télécharge le .zip
  6. Dépose le .zip directement dans l'app (pas besoin de décompresser)
Instagram
  1. Ouvre Instagram → Profil → ≡ → Paramètres et activité
  2. Ton activité → Télécharger tes informations
  3. Sélectionne "Certaines de tes informations" et coche au minimum :
    Activités (likes, vues), Connexions (abonnements), Recherches
  4. Format : JSON — Période : choisir la plus longue disponible
  5. Clique "Créer les fichiers" — délai : quelques minutes à 48h
  6. Télécharge le .zip reçu par e-mail et dépose-le dans l'app
⚠ Format JSON obligatoire. Si tu sélectionnes HTML, les données ne pourront pas être analysées. Sur Instagram, vérifie bien que "JSON" est coché avant de valider.

Avant de lancer l'analyse

Tes données comportementales sont lues dans ton navigateur ; seuls des signaux résumés (thèmes, comptes, recherches) sont envoyés à l'IA d'Anthropic pour générer le rapport. Aucune donnée n'est conservée après la session. Le rapport est fait de pistes à discuter avec un conseiller, jamais de verdicts — tu peux les contester ou les ignorer.
